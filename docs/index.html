What the labels mean

✕
Do not merge
A real problem was found. The row says what.
!
Needs a look
No malicious code found, but a maintainer should read the remark.
~
Quick scan only
A pattern scan ran. Nobody read the change.
✓
Clean
Nothing malicious found in what was checked. Not a guarantee.

A row tagged "Changed since review" means the pull request got a new commit after it was read: its verdict is about the earlier code, and it needs another look.

Every review here is a static, AI-assisted reading of a pull request's diff. Nothing was run. "How it was checked" on each row says what was actually done, and by whom. Rows tagged "Automated scan" come from a monitor that matches patterns in added lines: its hits are leads to look at, not conclusions.

Want to help?

Anyone can add reviews. You need a GitHub account and an AI agent that can read a pull request's diff.

  1. Pick a PR nobody checkedSearch for its number on this page. If it is not here, it is free to take.
  2. Give your agent the group's promptIt says what to look for and how to write the review file, so everyone's reviews line up.
  3. Send your review filesOpen a pull request on the repository with one small file per PR you checked.

One rule above all: read the diff, never run a PR's code.
